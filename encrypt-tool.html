Encrypt the Operating Manual

Runs entirely on this device. Your passphrase is never sent anywhere and is not stored in the output.
Step 1

Pick the unencrypted app file

Either Operating_Manual_phone.html or phone_hosted/index.html — both hold the same content.

Step 2

Choose a passphrase

Pick something you will remember. There is no recovery — if you lose it, the file cannot be opened and you would have to encrypt a fresh copy.

Step 3

Build the locked file

The file you download is called index.html. Upload it to your host in place of the unencrypted one, alongside manifest.webmanifest, sw.js and the two icons. Anyone who opens the address without the passphrase sees only a lock screen — the content is AES-256-GCM ciphertext, not hidden text.

This tool contains no personal data of any kind, so it is safe to keep or host. The unencrypted source file is the one to keep off the internet.
